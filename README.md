# trabajo01indtd2026
Trabajo 1 individual de Teoría de la Decisión

Objetivo: Presentar la resolución de dos problemas prácticos de toma de decisiones bajo incertidumbre
utilizando erramientas de programación en R, Quarto y renderizar con Typst.

Contenido de los problemas: 
Problema 1: Análisis de tres opciones de expansión logística para una empresa de comercio electrónico. Incluye matrices de decisión tanto para situación favorable (beneficios) como desfavorable (costes), preguntas de selección múltiple (verdadero/falso) razonadas, y la aplicación individual de los diferentes criterios (Wald, Optimista, Hurwicz, Laplace y Savage).
Problema 2 : Evaluación de la viabilidad estratégica para la instalación de una planta de ensamblaje de componentes fotovoltaicos en Andalucía (Sevilla, Málaga y Huelva). Su resolución se lleva a cabo aplicando la función global de la asignatura que evalúa todos los criterios de forma conjunta.

Estructura de Ficheros de Repositorio:
trabajo01.qmd: Código fuente del documento en Quarto con todo el texto, tablas y bloques de código en R.
teoriadecision_funciones_incertidumbre.R: Script de funciones proporcionado por la asignatura para el cálculo de los criterios de decisión.
trabajo01.pdf: Documento final compilado a PDF utilizando Typst.
trabajo01.html: Documento final HTML.
